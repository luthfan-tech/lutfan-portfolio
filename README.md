## 🛠️ Architecture & Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, React Server Components)
- **3D Graphics & Spatial Canvas**: [Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
- **Animation & Motion**: [GSAP](https://greensock.com/gsap/) (`@gsap/react`) & CSS Keyframes
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom spatial gradients
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Audio**: Web Audio API with custom tactile foley sound design

## 🚀 Getting Started

### Prerequisites
- Node.js 18.17+ or 20+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/luthfan-tech/lutfan-portfolio.git

# Navigate into directory
cd lutfan-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the result.

### Production Build
```bash
npm run build
npm start
```

## 🌐 Deployment Guidelines

### Primary Deployment: Vercel / Netlify
1. Import the GitHub repository into [Vercel](https://vercel.com/) or [Netlify](https://www.netlify.com/).
2. Framework Preset: `Next.js`.
3. Root Directory: `./`.
4. Build Command: `npm run build` (or `next build`).
5. Output Directory: `.next`.
