## 🕹️ Key Features & Interactive Systems

1. **Procedural 3D Voxel Typography Centerpiece**
   - Renders `LUTFAN MOHAMMED ASIF` using procedural voxel geometry.
   - Zero `.glb` download latency with instantaneous first paint (< 100ms TTI).
   - Smooth 60/120 FPS cursor parallax and spring-damped interactive tilt.

2. **Smart 3D Aerodynamic Cursor**
   - Modeled after a custom pillowy aerodynamic delta pointer with 3D specular ridge bevels.
   - **Dynamic Surface Luminance Detection**: Automatically turns luminous white/emerald over dark surfaces and obsidian dark over light surfaces.
   - Interactive reticle expansion and click recoil.

3. **Retro CRT Computer Bot & Interactive CLI Shell (Easter Egg)**
   - 3D CRT desktop unit with responsive green slit eyes (`//`), floppy drive, and a potted plant companion.
   - Clicking the CRT triggers a bounce animation and boots an interactive retro terminal shell:
     - `help` &rarr; List of secret terminal commands
     - `skills` &rarr; Systems breakdown
     - `matrix` &rarr; Matrix digital phosphor rain
     - `sudo` &rarr; Playful permission rejection
     - `coffee` &rarr; Direct Buy Me a Coffee route

4. **Floating Spatial Tech Artifacts**
   - **Mechanical Keycaps**: Clear acrylic switch with glowing emerald `+` cross stem and matte off-white PBT keycap with tactile asterisk `*`.
   - **Developer Breadboard Lab**: Solderless breadboard, microcontroller DIP unit, arched jumper wires, and a pulsing 5mm emerald LED (`#5DD62C`).
   - **Articulated Robotic Arm**: Industrial cybernetic arm with obsidian & white armor, inverse-kinematics cursor tracking, and mechanical gripper pinches.

5. **Calibrated Studio Display Desktop Workstation**
   - Sleek modern monitor mounted on an aluminum L-stand with subtle ambient emerald underglow.
   - Clicking toggles between **Deep Cosmic Emerald Aurora Wallpaper** and **Live Kernel Telemetry Terminal** with real-time FPS and system specs.

6. **Interactive Buy Me a Coffee Support**
   - Integrated with official link `buymeacoffee.com/luthfanmakl`.
   - Modal with official QR code and 1-click link copying with feedback toasts.

7. **Dual-Tier Graceful 2D Fallback & Accessibility**
   - If WebGL is disabled or on low-power devices, activates custom CSS/SVG vector fallbacks (`Hero2DFallback`, `Computer2DFallback`).
   - Tactile foley sound design with persistent mute toggle.

## 🚀 Local Development

### 1. Clone & Install
```bash
git clone https://github.com/luthfan-tech/lutfan-portfolio.git
cd lutfan-portfolio
npm install
```

### 2. Start Dev Server
```bash
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
